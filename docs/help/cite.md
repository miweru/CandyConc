# Cite CandyConc

If CandyConc contributed to your research, cite the software with the
version you used. The citation information is kept in the file
`CITATION.cff` at the root of the repository, and GitHub shows it as
**Cite this repository** on the repository page, in APA and BibTeX form.

## Citation

Ruppert, Michael. *CandyConc* (version 0.1.1). Software.
<https://github.com/miweru/CandyConc>

As BibTeX:

```bibtex
@software{candyconc,
  author  = {Ruppert, Michael},
  title   = {CandyConc},
  version = {0.1.1},
  url     = {https://github.com/miweru/CandyConc}
}
```

CandyConc has no DOI. Name the version, because counts and methods can change
between versions: `candy --version` prints it, and the footer of this
documentation shows the version it describes.

## Make results traceable

A citation of the software does not say how a number was computed. Report
with each result the corpus, the query, the scope, and the settings that the
method card shows, or publish the evidence package of the concordance. See
[Reproduce a result](../guides/keep-and-share/reproduce-a-result.md) and
[Export formats](../reference/export-formats.md#evidence-packages).

## Cite the methods and the data

- The statistical measures come from the publications listed in the
  [Bibliography](../methods/bibliography.md). Cite them for the measures you
  report.
- Cite the source of your corpus. For the sample corpora of this
  documentation, see [Licenses](license.md#sample-corpora).
