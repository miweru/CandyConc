Configuration reference#

CandyConc works without any configuration. This page lists the settings that you can change: first the decisions a researcher makes (which language model, which corpus at start), then the settings for running CandyConc for others (locations, security, logs, limits). Every setting has the same name in the environment and in the configuration file.

The settings listed on this page are the supported configuration. Names that the code reads but that are not listed here are internal and can change without notice.

Where settings come from#

CandyConc reads each setting from the first of these sources that has it:

  1. A change at runtime. Settings > Model connection in the web interface changes the endpoint, model, and key of the copilot at once. The change lasts until the server stops and is not written to a file.

  2. The environment of the server process, for example COPILOT_MODEL=my-model candy.

  3. The configuration file config.toml. candy paths prints its location. The default location is ~/Library/Application Support/candyconc/config.toml on macOS and $XDG_CONFIG_HOME/candyconc/config.toml (usually ~/.config/candyconc/config.toml) on Linux. CANDYCONC_CONFIG_FILE points to another file.

  4. [tool.candyconc] in app/pyproject.toml, only when CandyConc runs from a source checkout (with PYTHONPATH=src or an editable install) and the file has this table. An installed wheel has no such file.

  5. The default in the code, listed in the tables on this page.

Command line options of candy (--enable-rbac, --log-level, --log-file) set the corresponding setting for one start.

All settings except the runtime change in the first source take effect when the server starts. Restart the server after you change the environment or the configuration file.

The configuration file#

The configuration file is TOML. Each line sets one setting with the same name as the environment variable. Values are text, numbers, or true and false. Tables and lists are not allowed. Example:

COPILOT_ENDPOINT = "http://127.0.0.1:1234/v1/responses"
COPILOT_MODEL = "qwen3-30b-a3b"
CANDYCONC_LOG_LEVEL = "WARNING"

A file that is not valid TOML, or that contains a table or a list, stops the server at start with a message that names the file and the problem. A setting in the environment always wins over the same setting in the file.

User decisions#

Language model for the copilot#

The copilot is optional. Without COPILOT_ENDPOINT every other function works and the chat answers that no language model is configured. Settings > Model connection in the web interface changes endpoint, model, and key at once, until the server stops.

Setting

Default

Effect

COPILOT_ENDPOINT

not set

Address of an OpenAI-compatible endpoint, ending in /v1/responses or /v1/chat/completions, for example http://127.0.0.1:1234/v1/responses for a local server. Empty: no copilot.

COPILOT_MODEL

qwen3-30b-a3b

Model name that the endpoint expects. CandyConc checks the model field of every answer and stops with an error when the endpoint answers with a different model.

COPILOT_API_KEY

lm-studio

Key sent as Authorization: Bearer to the endpoint. Local servers usually accept any value.

COPILOT_REASONING_EFFORT

not set

Reasoning effort (low, medium, high) for providers that support it. Unset: not sent.

COPILOT_THINKING_MODE

not set

For models of the Qwen3 family: off adds /no_think, on adds /think to the question. Unset: unchanged.

Passage search with a remote embedding model#

These settings matter only for a corpus whose passage index was built with a remote embedding model. Similar words use the word vectors of the annotation pipeline of each corpus, see Languages and annotation pipelines.

Setting

Default

Effect

CANDYCONC_GEMMA_EMB_ENDPOINT

http://127.0.0.1:1234/v1/embeddings

OpenAI-compatible embeddings endpoint for passage search in such a corpus. The search text is sent to this endpoint.

CANDYCONC_GEMMA_EMB_MODEL

google/embedding-gemma-300m

Model name for CANDYCONC_GEMMA_EMB_ENDPOINT.

Corpus at start#

Without these settings the server opens the active corpus of the corpus catalog, or the most recent corpus in the data directory.

Setting

Default

Effect

CANDYCONC_INDEX_PATH

not set

Directory of a corpus index that the server opens at every start. The server refuses to start when the directory is not a complete index. The HTTP API addresses this corpus with the name default, and the corpus catalog gives the folder name in display_name.

Administration#

Locations#

candy paths prints the locations that are in effect. See Where your data lives.

Setting

Default

Effect

CANDYCONC_HOME

~/.candyconc

Data directory: corpora, corpus catalog, project file, preferences, logs, downloaded pipelines, temporary files.

CANDYCONC_CONFIG_FILE

config.toml in the platform configuration directory

Location of the configuration file. The default is ~/Library/Application Support/candyconc/config.toml on macOS and $XDG_CONFIG_HOME/candyconc/config.toml (usually ~/.config/candyconc/config.toml) on Linux.

CANDYCONC_PROJECT_FILE

not set

Project file with subcorpora, line annotations, and the coding scheme. Empty: proj.ccproj in the working directory if one exists there (older versions kept it there), otherwise proj.ccproj in the data directory. A relative path is resolved against the working directory.

CANDYCONC_PROJECTS_DIR

not set

Directory with saved analyses, cluster lists, and project members. Empty: config/projects in the working directory if it exists there, otherwise projects in the data directory.

CANDYCONC_PREFS_PATH

prefs.json in the data directory

File with the saved preferences of the web interface.

index_dir

not set

Same as CANDYCONC_INDEX_PATH, as a setting of the configuration file (environment name INDEX_DIR). CANDYCONC_INDEX_PATH wins when both are set.

CANDYCONC_FRONTEND_DIST

not set

Directory of a built web interface to serve instead of the one in the package. The directory must contain index.html.

Security and access#

The two security modes are described in Deployment.

Setting

Default

Effect

CANDYCONC_SECURITY_MODE

local_dev_unsafe

local_dev_unsafe: single-user mode, bound to the local computer, no sign-in. release: multi-user mode with sign-in, roles, host check, and without the OpenAPI pages.

CANDYCONC_ENABLE_RBAC

off

Role-based access control. Multi-user mode needs it. candy --enable-rbac sets it for one start.

CANDYCONC_USER_FILE

config/users.json

User file with password hashes and roles, written by python -m candyconc.tools.user_bootstrap. Multi-user mode does not start without at least one user. An absolute path is used directly. A relative path is first resolved from the installation. If that file is absent, CandyConc reads users.json from its data directory.

CANDYCONC_TRUSTED_HOSTS

localhost,127.0.0.1,::1,testserver

Comma-separated host names that multi-user mode accepts in the Host header. Add the host name of your server or reverse proxy. * switches the check off.

CANDYCONC_TOKEN_TTL_SECONDS

43200 (12 hours)

Lifetime of a sign-in token in seconds. 0: tokens do not expire.

CANDYCONC_ALLOW_UNSAFE_NETWORK_DEV

not set

1 lets single-user mode bind to a network address. Without it, candy --host 0.0.0.0 stops in single-user mode. Anyone who reaches the address then has full access.

CANDYCONC_ENABLE_COPILOT_PII_MASK

on

Replaces e-mail addresses, IBANs, and telephone numbers in the question and the interface context with placeholders before they reach the language model. It does not mask the tool results, which contain corpus text.

CANDYCONC_ENABLE_PII_MASK

off

Replaces concordance tokens with <PII> when their indexed entity label is recognized. Requires named entity annotations. Recognizes English labels such as PERSON, but not the German person label PER. This corpus-text masking is independent of CANDYCONC_ENABLE_COPILOT_PII_MASK. See Languages and annotation.

Logs#

Setting

Default

Effect

CANDYCONC_LOG_LEVEL

INFO

Log level of the server: DEBUG, INFO, WARNING, or ERROR. candy --log-level sets it for one start.

CANDYCONC_LOG_FILE

not set

File that receives the server log in addition to the terminal. candy --log-file sets it for one start.

CANDYCONC_AUDIT_LOG_PATH

logs/audit.jsonl in the data directory

Log of sign-ins, failed sign-ins, sign-outs, and WebSocket tickets, one JSON object per line, rotated at 5 MiB. off switches it off.

CANDYCONC_ENABLE_LLM_TRACE

not set

Record of every call to the language model in traces.jsonl in the data directory: user, model, tool names, and for each message its role and size, without the text. Unset: on in single-user mode, off in multi-user mode.

Request limits#

Limits protect a shared server. A request above a limit receives an error, the server never shortens a result without saying so.

Setting

Default

Effect

CANDYCONC_RATE_LIMIT_ANON

300

Requests per minute and client address without a token. 0: no limit.

CANDYCONC_RATE_LIMIT_DEFAULT

600

Requests per minute and user with a token. 0: no limit.

CANDYCONC_MAX_REQUEST_BYTES

8388608 (8 MiB)

Largest request body. Larger requests receive 413. 0: no limit.

CANDYCONC_QUERY_MAX_CONTEXT

600

Largest context width, in tokens on each side of a hit.

CANDYCONC_ANALYSIS_PAGE_LIMIT_MAX

5000

Largest page of result rows that one request may ask for.

CANDYCONC_ANALYSIS_JOB_TOP_N_MAX

50000

Largest number of rows that an analysis job keeps.

CANDYCONC_ANALYSIS_NGRAM_MAX_N

5

Longest n-gram.

CANDYCONC_ANALYSIS_COLLOCATE_MAX_WINDOW

50

Largest collocation window, in tokens on each side.

CANDYCONC_ANALYSIS_RESULT_MAX_BYTES

134217728

Largest result of one analysis job, in bytes.

CANDYCONC_ALIGNMENT_MAX_EDIT_CELLS

12000000

Largest sentence alignment of paired texts, in comparisons. A larger alignment is refused, not shortened.

CANDYCONC_MAX_REGEX_TYPES

200000

Largest number of distinct values matched by a regular expression when concordance lines are requested. Larger matches are rejected. Set this environment variable before starting the server.

CANDYCONC_MAX_REGEX_FREQ

5000000

Largest summed corpus frequency, in tokens, of the values matched by a regular expression when concordance lines are requested. Larger matches are rejected. Set this environment variable before starting the server.

Copilot operation#

The time limits are safeguards against a connection that hangs. A question can legitimately take long on slow hardware.

Setting

Default

Effect

COPILOT_TIMEOUT

8000000

Time limit in seconds for one call to the language model. 0: no limit.

CANDYCONC_COPILOT_MAX_TIME_SEC

no budget

Time budget in seconds for one copilot turn. Empty or 0: no budget.

CANDYCONC_LM_STUDIO_REQUIRE_LOADED_MODEL

on

For endpoints on the local computer: check the model list of the endpoint before each question and answer 424 when the model is not loaded. The check never loads a model.

CANDYCONC_MAX_COPILOT_STEPS

240

Largest number of tool steps that one question may use. A client that requests more is limited to this value.

CANDYCONC_COPILOT_MAX_QUESTION_CHARS

8000

Longest question in characters. Longer questions receive 413.

CANDYCONC_COPILOT_MAX_MESSAGES

50

Largest number of messages in one chat request.

CANDYCONC_COPILOT_MAX_HISTORY_CHARS

64000

Largest total length of the messages in one chat request, in characters.

CANDYCONC_MCP_URL

not set

Address of a remote CandyConc tool service. When set, the copilot sends every tool call with its arguments to <address>/mcp/call instead of running it in the server, and uses the results that come back. Leave it empty to run the tools in the server itself.

CANDYCONC_MODEL_CONTEXT_TOKENS

173312

Context window of the model in tokens. CandyConc shortens the working record of a question in the model's copy before it outgrows this window. Set it to the context size of your model if that is smaller.

COPILOT_RECIPE_CLASSIFIER_TIMEOUT_S

not set

Time limit in seconds of the model call that chooses the analysis recipe. Unset, the limit is 300 seconds. When it runs out, the question continues with the recipe from the keyword rules or without a recipe.

Import#

Before an import CandyConc estimates the disk space the index needs and refuses the import when the volume of the output directory has too little free space.

Setting

Default

Effect

CANDYCONC_BUILD_DISK_FACTOR

2.5

Estimated index size as a multiple of the input size.

CANDYCONC_BUILD_DISK_RESERVE_GB

5

Free space in GB that must remain after the estimated index size.

CANDYCONC_BUILD_ALLOW_LOW_DISK

not set

1 turns the refusal into a warning.

Other#

Setting

Default

Effect

CANDYCONC_VERSION

the package version

Label of a deployment that GET /api/v1/system/info reports instead of the package version.

CANDYCONC_NO_BROWSER

not set

1 makes ./candyconc of the application bundle start without opening the browser.

Settings of the web interface#

The Settings dialog of the web interface keeps display preferences such as results per page and the interface language. The server saves them in the preferences file listed under Locations, and the browser keeps a copy. They are not part of this configuration. The interface is described in Interface reference.
