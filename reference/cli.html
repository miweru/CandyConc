Command line reference#

CandyConc installs one command, candy. Without a subcommand it starts the server and the web interface. The subcommands import corpora, download annotation pipelines, show where CandyConc keeps its data, and migrate old project files.

Command

Purpose

candy

Start the server and the web interface.

candy import

Import a corpus: build a corpus index from CSV, JSONL, plain text, Parquet, VRT, a Hugging Face dataset, or paired files.

candy pipeline NAME

Download and install a spaCy annotation pipeline, for example en_core_web_sm.

candy paths

Show where CandyConc keeps its data and where it reads its configuration file.

candy migrate-project

Migrate a project file of an older version.

candy --version

Show the versions of CandyConc and Python.

python -m candyconc.entrypoints.cli is the same command, with the same arguments. candy serve is the same as candy without a subcommand.

The application bundle has its own launcher, ./candyconc, with slightly different commands. It is described in The launcher of the application bundle.

Starting the server#

candy prints the version, the address of the web interface, the corpus it opens, the data directory, and whether a language model for the copilot is configured. The output is similar to the following:

CandyConc 0.1.1 (Python 3.12.8)
  Web interface: http://127.0.0.1:8010/
  Corpus: none yet. Import one in the web interface (Corpora) or with: candy import --help
  Data: /home/USER/.candyconc
  Copilot: no language model configured (optional, see Settings > Model connection)
Press Ctrl+C to stop.

  • Port. Without --port, CandyConc uses port 8010, or the next free port up to 8029 when 8010 is taken. With --port, it uses exactly that port and stops with Port N on HOST is already in use when the port is taken.

  • Corpus. The server opens the corpus in CANDYCONC_INDEX_PATH if it is set, otherwise the active corpus of the corpus catalog, otherwise the most recent corpus in the data directory. Without any corpus it starts with an empty catalog, and the web interface offers the import.

  • Address. The server binds to 127.0.0.1, so only programs on the same computer reach it. A network address needs multi-user mode, see Deployment.

  • Web interface. When the built interface is missing (possible in a development checkout), the server prints API only at ... and serves only the API.

candy import in brief#

candy import builds a corpus index in the directory given with --output. If that directory already holds an index, the new one replaces it when the import has finished, and a running server opens it with the next request. The format follows from the file extension unless you set --input-format. Which options apply to which format:

Options

Formats

--text-column, --id-column, --meta-columns

csv, jsonl, parquet, hf, and the paired formats

--reject-policy, --reject-report

csv, jsonl, parquet, hf, plaintext, and the paired formats

--source

all formats

--delimiter

csv, prealigned-csv

--pair-key-column, --pair-role-column, --anchor-role, --pair-axis, --pair-order, --variant-column, --model-column

prealigned-csv, prealigned-jsonl, prealigned-parquet

--pattern, --split-paragraphs

plaintext

--segment-tag, --text-tag, --sentence-tag, --token-columns, and the other options marked VRT

vrt

--hf-config, --hf-split, --limit

hf (needs the hf extra, see Supported platforms and requirements)

--language, --spacy-model, --no-deps, --enable-deps, --enable-ner, --batch-size, --n-process, --max-doc-chars, --no-split-long-texts, --meta-index-fields

all formats

--language or --spacy-model chooses the annotation pipeline, and dependency relations are added when the pipeline has a parser. See Choosing the pipeline. Before the import starts, candy import checks that the pipeline is installed. If it is not, it stops with a message that names the command to install it and the tokenization-only alternative, for example blank:en. The columns and fields of each format are described in Input formats. The annotation pipelines are described in Languages and annotation pipelines.

candy pipeline#

candy pipeline NAME looks up the release of the spaCy pipeline NAME that fits the installed spaCy, downloads it from GitHub (explosion/spacy-models), and installs it into the Python environment of CandyConc with pip (or uv, in environments that uv created without pip). CandyConc never downloads a pipeline on its own. blank:<language> needs no download. With --user-dir, the pipeline goes into the data directory (~/.candyconc/pipelines) instead, and with --print-url the command only prints the address of the download.

candy paths#

candy paths prints the locations that CandyConc uses on this computer. The output is similar to the following:

data dir           /home/USER/.candyconc
config file        /home/USER/.config/candyconc/config.toml
corpora dir        /home/USER/.candyconc/corpora
corpus catalog     /home/USER/.candyconc/corpora.json
project file       /home/USER/.candyconc/proj.ccproj
projects dir       /home/USER/.candyconc/projects
logs dir           /home/USER/.candyconc/logs
pipelines dir      /home/USER/.candyconc/pipelines

What each location holds is described in Where your data lives.

candy migrate-project#

Project files of older versions (SQLite, or JSON of an older layout) are not converted automatically. candy migrate-project FILE checks such a file and reports what it contains without changing anything. With --output NEW_FILE it writes a migrated copy, and with --in-place --backup BACKUP_FILE it replaces the file after copying it to BACKUP_FILE. See Upgrade CandyConc.

All commands and options#

The following tables are generated from the argument parsers of candy, so they match the installed version. candy COMMAND --help prints the same information.

candy#

CandyConc: corpus analysis in the browser. Starts the server and the web interface.

usage: candy [-h] [--version] [--host HOST] [--port PORT] [--open]
             [--enable-rbac] [--log-level LOG_LEVEL] [--log-file LOG_FILE]
-h, --help

Show this help message and exit.

--version

Show program's version number and exit.

--host HOST

Bind address (default: 127.0.0.1, loopback only). A network address such as 0.0.0.0 is refused in the default single-user mode. Use it with CANDYCONC_SECURITY_MODE=release and --enable-rbac.

--port PORT

Port (default: 8010, or the next free one when it is taken).

--open

Open the web interface in the browser. Off unless given.

--enable-rbac

Enforce role-based access control. Off unless given.

--log-level LOG_LEVEL

Log level, for example DEBUG or WARNING (default: INFO).

--log-file LOG_FILE

Also write the log to this file.

candy import#

Import a corpus: build a Fast Index from CSV, JSONL, plain text, Parquet, VRT, a Hugging Face dataset or paired (pre-aligned) files.

usage: candy import [-h] --input INPUT --output OUTPUT
                    [--input-format {parquet,vrt,prealigned-parquet,prealigned-csv,prealigned-jsonl,prealigned_parquet,prealigned_csv,prealigned_jsonl,plaintext,csv,jsonl,hf}]
                    [--language LANGUAGE] [--spacy-model SPACY_MODEL]
                    [--batch-size BATCH_SIZE] [--n-process N_PROCESS]
                    [--include-prompts] [--enable-ner] [--enable-deps]
                    [--no-deps] [--no-split-long-texts]
                    [--allow-missing-input-text]
                    [--max-doc-chars MAX_DOC_CHARS]
                    [--meta-index-fields META_INDEX_FIELDS]
                    [--no-capture-whitespace] [--segment-tag SEGMENT_TAG]
                    [--text-tag TEXT_TAG] [--sentence-tag SENTENCE_TAG]
                    [--source SOURCE] [--register REGISTER]
                    [--min-text-chars MIN_TEXT_CHARS] [--variant VARIANT]
                    [--model MODEL] [--token-columns TOKEN_COLUMNS]
                    [--token-separator {auto,tab,whitespace}]
                    [--word-column WORD_COLUMN] [--strict-columns]
                    [--join-mode {smart,space}] [--id-attrs ID_ATTRS]
                    [--source-attrs SOURCE_ATTRS]
                    [--register-attrs REGISTER_ATTRS]
                    [--date-attrs DATE_ATTRS] [--genre-attrs GENRE_ATTRS]
                    [--annotation-mode {none,sidecar,adopt}] [--inspect]
                    [--inspect-docs INSPECT_DOCS] [--text-column TEXT_COLUMN]
                    [--id-column ID_COLUMN]
                    [--pair-key-column PAIR_KEY_COLUMN]
                    [--pair-role-column PAIR_ROLE_COLUMN]
                    [--anchor-role ANCHOR_ROLE] [--pair-axis PAIR_AXIS]
                    [--pair-order {unsorted,grouped,sorted}]
                    [--meta-columns [META_COLUMNS ...]]
                    [--variant-column VARIANT_COLUMN]
                    [--model-column MODEL_COLUMN] [--delimiter DELIMITER]
                    [--reject-policy {collect,fail_fast}]
                    [--reject-report REJECT_REPORT] [--pattern PATTERN]
                    [--split-paragraphs] [--hf-config HF_CONFIG]
                    [--hf-split HF_SPLIT] [--limit LIMIT]
-h, --help

Show this help message and exit.

--input INPUT

Input file, a folder of .txt files for plain text, or a dataset ID for --input-format hf. Required.

--output OUTPUT

Directory of the corpus index, for example ~/.candyconc/corpora/NAME. An index already there is replaced when the import has finished. Required.

--input-format INPUT_FORMAT

Input format (default: from the file extension: .csv/.tsv csv, .jsonl/.ndjson jsonl, .txt or a folder plaintext, .parquet parquet, .vrt/.xml vrt). Values: parquet, vrt, prealigned-parquet, prealigned-csv, prealigned-jsonl, prealigned_parquet, prealigned_csv, prealigned_jsonl, plaintext, csv, jsonl, hf.

--language LANGUAGE

ISO 639 code of the corpus language, for example en or de. Selects the standard spaCy pipeline for it (en: en_core_web_md, de: de_core_news_md), or blank:<language> when spaCy has no trained one.

--spacy-model SPACY_MODEL

SpaCy pipeline for tokenization and annotation, for example en_core_web_sm or de_core_news_md (install with: candy pipeline <name>), or blank:<language> for tokenization only (default: the standard pipeline of --language, without --language de_core_news_md).

--batch-size BATCH_SIZE

Texts per spaCy batch (default: 0, chosen from free memory).

--n-process N_PROCESS

SpaCy worker processes (default: 0, chosen from CPU cores).

--include-prompts

Parquet and VRT: keep the prompt text of generated variants as document metadata. Off unless given.

--enable-ner

Add named entities (attribute ent). Off unless given.

--enable-deps

Add dependency relations (attributes rel and head), needed for word sketches. Default: on when the pipeline has a parser, except VRT annotation adoption.

--no-deps

Import without dependency parsing. On unless given.

--no-split-long-texts

Keep texts longer than --max-doc-chars as one document instead of splitting them. On unless given.

--allow-missing-input-text

Parquet and VRT: accept rows without the input_text column. Off unless given.

--max-doc-chars MAX_DOC_CHARS

Longer texts are split at paragraph or whitespace boundaries (default: 1000000).

--meta-index-fields META_INDEX_FIELDS

Comma-separated metadata fields for the filter index (default: all fields).

--no-capture-whitespace

Do not record the spacing between tokens (whitespace_after.bin). Concordance lines and texts then show every token separated by a space, for example "soul . No" instead of "soul. No". On unless given.

--segment-tag SEGMENT_TAG

VRT: element that becomes one document. Default: text.

--text-tag TEXT_TAG

VRT: parent element that carries text metadata. Default: text.

--sentence-tag SENTENCE_TAG

VRT: sentence element. Default: s.

--source SOURCE

Value of the source metadata field (vrt: used when no source attribute is found).

--register REGISTER

VRT: fallback value of the register metadata field.

--min-text-chars MIN_TEXT_CHARS

VRT: skip documents with fewer characters. Default: 1.

--variant VARIANT

VRT: value of the variant metadata field. Default: document.

--model MODEL

VRT: value of the model metadata field. Default: none.

--token-columns TOKEN_COLUMNS, --columns TOKEN_COLUMNS

VRT: comma-separated names of the token columns, for example word,lemma,pos.

--token-separator TOKEN_SEPARATOR

VRT: separator between token columns. Values: auto, tab, whitespace. Default: auto.

--word-column WORD_COLUMN

VRT: column (name or number) with the word form. Default: word.

--strict-columns

VRT: stop at a token line with a different number of columns. Off unless given.

--join-mode JOIN_MODE

VRT: how tokens are joined into the document text (smart: no space before punctuation). Values: smart, space. Default: smart.

--id-attrs ID_ATTRS

VRT: attributes that hold the document ID, comma-separated.

--source-attrs SOURCE_ATTRS

VRT: attributes that hold the source, comma-separated.

--register-attrs REGISTER_ATTRS

VRT: attributes that hold the register, comma-separated.

--date-attrs DATE_ATTRS

VRT: attributes that hold the date, comma-separated.

--genre-attrs GENRE_ATTRS

VRT: attributes that hold the genre, comma-separated.

--annotation-mode ANNOTATION_MODE

VRT: annotate with spaCy and keep supplied columns separately (sidecar), drop them (none), or index them unchanged (adopt). Values: none, sidecar, adopt. Default: sidecar.

--inspect

VRT: print what the file contains without building an index. Off unless given.

--inspect-docs INSPECT_DOCS

VRT: documents shown by --inspect. Default: 3.

--text-column TEXT_COLUMN

Column with the text. Default: text.

--id-column ID_COLUMN

Column with the document ID. Default: id.

--pair-key-column PAIR_KEY_COLUMN

Paired import: column that groups the variants of one text. Default: pair_id.

--pair-role-column PAIR_ROLE_COLUMN

Paired import: column with the role of each variant. Default: pair_role.

--anchor-role ANCHOR_ROLE

Paired import: role of the variant the others are aligned to. Default: source.

--pair-axis PAIR_AXIS

Paired import: name of the pairing recorded in the manifest. Default: prealigned.

--pair-order PAIR_ORDER

Paired import: grouped or sorted input streams one group at a time, unsorted keeps all rows in memory. Values: unsorted, grouped, sorted. Default: unsorted.

--meta-columns META_COLUMNS ...

Columns to keep as document metadata, separated by spaces (default: none).

--variant-column VARIANT_COLUMN

Paired import: column with the variant name.

--model-column MODEL_COLUMN

Paired import: column with the name of the generating model.

--delimiter DELIMITER

CSV: field separator (default: detected).

--reject-policy REJECT_POLICY

Collect: skip invalid rows and list them in the rejected rows report, fail_fast: stop at the first one. Values: collect, fail_fast. Default: collect.

--reject-report REJECT_REPORT

Also write every rejected row to this JSON Lines file (reject_report.json in the index always lists the counts and up to 50 rows).

--pattern PATTERN

Plain text: file pattern inside the input folder. Default: *.txt.

--split-paragraphs

Plain text: one document per paragraph instead of one per file. Off unless given.

--hf-config HF_CONFIG

Hugging Face: dataset configuration.

--hf-split HF_SPLIT

Hugging Face: dataset split. Default: train.

--limit LIMIT

Hugging Face: import at most this many rows.

candy pipeline#

Download and install a spaCy pipeline from GitHub (explosion/spacy-models). CandyConc never downloads pipelines by itself.

usage: candy pipeline [-h] [--target TARGET | --user-dir] [--print-url] name
-h, --help

Show this help message and exit.

name

Pipeline package, e.g. en_core_web_sm, de_core_news_md. Required.

--target TARGET

Install into this directory instead of the Python environment.

--user-dir

Install into the CandyConc data directory (~/.candyconc/pipelines). Off unless given.

--print-url

Only print the download URL. Off unless given.

candy migrate-project#

Migrate a legacy .ccproj project without implicit data rewrites.

usage: candy migrate-project [-h] [--output OUTPUT | --in-place]
                             [--backup BACKUP] [--dry-run]
                             project
-h, --help

Show this help message and exit.

project

Legacy .ccproj or JSON project file. Required.

--output OUTPUT

Write a new migrated project file.

--in-place

Replace the source after backup. Off unless given.

--backup BACKUP

Required backup path for --in-place.

--dry-run

Validate and report without writing. Off unless given.

The launcher of the application bundle#

The application bundle contains a launcher script, ./candyconc, in the unpacked folder. It runs the CandyConc of the bundle with the Python of the bundle and passes most commands on to candy.

Launcher command

What it does

./candyconc

Starts the server in the data directory and opens the web interface in the browser. Set CANDYCONC_NO_BROWSER=1 to start without opening the browser.

./candyconc import ...

Same as candy import ....

./candyconc pipeline NAME

Installs the spaCy pipeline NAME into ~/.candyconc/pipelines, so that it stays when you replace the bundle with a newer one.

./candyconc paths

Same as candy paths.

./candyconc version

Shows the versions of CandyConc, Python, and spaCy, and the location of the bundle.

./candyconc uninstall

Removes the bundle folder after a confirmation. --yes skips the confirmation. The data directory stays.

./candyconc help

Shows these commands.

./candyconc --port 8020, and any other option

Starts the server with these options, like candy.
